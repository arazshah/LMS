# معماری سیستم LMS (lms.araz.me)

سیستم آموزشی اختصاصی برای دوره‌های هوش مصنوعی مکانی. فقط یک مدرس/ادمین دارد و بقیه کاربران دانشجو هستند.

## تصمیم‌های کلیدی

| موضوع | تصمیم |
|---|---|
| زبان | فقط فارسی (RTL)، فونت Vazirmatn، تاریخ شمسی |
| بک‌اند | Django 5.2 (LTS) + PostgreSQL 17 |
| کارهای پس‌زمینه | Celery + Redis (تبدیل ویدیو، ارسال پیامک) |
| فرانت‌اند | قالب‌های Django + HTMX + Tailwind (بدون CDN خارجی؛ همه فایل‌ها روی سرور) |
| ورود | شماره موبایل + کد یک‌بارمصرف از sms.ir |
| پرداخت | ربات بله، کارت‌به‌کارت به کارت شخصی + تأیید دستی در پنل ادمین |
| ویدیو | روی سرور خودمان، تبدیل به HLS با ffmpeg، واترمارک متحرک (نام سایت + موبایل کاربر) |
| کلاس زنده | Google Meet؛ لینک فقط برای خریداران نمایش داده می‌شود |
| اطلاع‌رسانی | پیامک (sms.ir) |
| دیپلوی | GitHub → Coolify (Docker Compose) روی سرور ایران |

## مدل داده (برنامه)

```
Category ─< Course ─< Chapter ─< Lesson ─< LessonFile
              │  └── prerequisites (Course ↔ Course)
              │
Bundle >─< Course                 LiveClass ─< LiveSession (زمان + لینک Meet)

User ─< Order ─< OrderItem (Course | Bundle | LiveClass)
          ├── DiscountCode
          ├── Payment (بله / تأیید دستی)
          └── Invoice (PDF)

User ─< Access (Course | LiveClass, expires_at, source: order | manual)
User ─< Question (روی Lesson) ─< Answer (فقط ادمین)
OTPCode, SMSLog
```

- **Lesson.kind**: ویدیو، PDF/اسلاید، نوت‌بوک، داده مکانی، کد، متن
- **Lesson.is_free**: جلسه رایگان برای پیش‌نمایش
- **Course.access_days**: مدت دسترسی پس از خرید (زمان‌دار)
- خرید پکیج برای هر دوره داخل آن یک رکورد `Access` می‌سازد.

## روند خرید

1. کاربر دوره، پکیج یا کلاس زنده را به سبد اضافه می‌کند و کد تخفیف را وارد می‌کند.
2. سفارش ثبت می‌شود و کاربر به ربات بله هدایت می‌شود (`?start=<order_code>`).
3. ربات فاکتور پرداخت را می‌فرستد و کاربر کارت‌به‌کارت می‌کند.
4. بله پرداخت موفق را از طریق webhook به سرور اطلاع می‌دهد. سرور سفارش را پرداخت‌شده علامت می‌زند، `Access` می‌سازد، فاکتور PDF صادر می‌کند و پیامک می‌فرستد.
5. راه جایگزین: ادمین در پنل، سفارش را **دستی تأیید** می‌کند.

> جزئیات دقیق API پرداخت ربات بله در فاز ۳ بررسی و پیاده‌سازی می‌شود.

## امنیت محتوا

- فایل‌ها و ویدیوها از مسیر عمومی سرو نمی‌شوند. Django دسترسی را چک می‌کند و فایل با لینک امضاشده و موقت تحویل داده می‌شود.
- روی پلیر، واترمارک متحرک «lms.araz.me + شماره موبایل کاربر» نمایش داده می‌شود.

## تست

- **pytest** برای منطق و viewها. CI روی PostgreSQL واقعی اجرا می‌شود.
- **Playwright** برای روندهای کامل (ورود، خرید، تماشا) از فاز ۳.
- sms.ir و بله در تست‌ها شبیه‌سازی (mock) می‌شوند.
- GitHub Actions روی هر push: lint، بررسی migrationها، تست‌ها و ساخت ایمیج Docker.
