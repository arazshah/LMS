# معماری سیستم LMS (lms.araz.me)

سیستم آموزشی اختصاصی برای دوره‌های هوش مصنوعی مکانی. فقط یک مدرس/ادمین دارد و بقیه کاربران دانشجو هستند.

## تصمیم‌های کلیدی

| موضوع | تصمیم |
|---|---|
| زبان | فقط فارسی (RTL)، فونت Vazirmatn، تاریخ شمسی |
| بک‌اند | Django 5.2 (LTS) + PostgreSQL 17 |
| کارهای پس‌زمینه | Celery + Redis (تبدیل ویدیو، ارسال پیامک) |
| فرانت‌اند | قالب‌های Django + HTMX + Tailwind (بدون CDN خارجی؛ همه فایل‌ها روی سرور) |
| ورود | شماره موبایل + کد یک‌بارمصرف از sms.ir |
| پرداخت | ربات بله، کارت‌به‌کارت به کارت شخصی + تأیید دستی در پنل ادمین |
| ویدیو | روی سرور خودمان، تبدیل به HLS با ffmpeg، واترمارک متحرک (نام سایت + موبایل کاربر) |
| کلاس زنده | Google Meet؛ لینک فقط برای خریداران نمایش داده می‌شود |
| اطلاع‌رسانی | پیامک (sms.ir) |
| دیپلوی | GitHub → Coolify (Docker Compose) روی سرور ایران |

## مدل داده (برنامه)

```
Category ─< Course ─< Chapter ─< Lesson ─< LessonFile
              │  └── prerequisites (Course ↔ Course)
              │
Bundle >─< Course                 LiveClass ─< LiveSession (زمان + لینک Meet)

User ─< Order ─< OrderItem (Course | Bundle | LiveClass)
          ├── DiscountCode
          ├── Payment (بله / تأیید دستی)
          └── Invoice (PDF)

User ─< Access (Course | LiveClass, expires_at, source: order | manual)
User ─< Question (روی Lesson) ─< Answer (فقط ادمین)
OTPCode, SMSLog
```

- **Lesson.kind**: ویدیو، PDF/اسلاید، نوت‌بوک، داده مکانی، کد، متن
- **Lesson.is_free**: جلسه رایگان برای پیش‌نمایش
- **Course.access_days**: مدت دسترسی پس از خرید (زمان‌دار)
- خرید پکیج برای هر دوره داخل آن یک رکورد `Access` می‌سازد.

## روند خرید

1. کاربر روی «خرید دوره» یا «خرید پکیج» می‌زند و اگر کد تخفیف دارد آن را وارد می‌کند.
2. سفارش ثبت می‌شود و صفحه پرداخت دو روش را نشان می‌دهد:
   - **بله:** لینک `https://ble.ir/<bot>?start=<token>` ربات را باز می‌کند. ربات با `sendInvoice` فاکتور می‌فرستد که پولش به کارت تنظیم‌شده واریز می‌شود (مبلغ به ریال). بله پیام `successful_payment` را به webhook سایت (`/payments/bale/<secret>/`) می‌فرستد. سایت مبلغ را بررسی می‌کند و سفارش را پرداخت‌شده علامت می‌زند. صفحه پرداخت هر ۵ ثانیه وضعیت را چک می‌کند و خودکار به‌روز می‌شود.
   - **کارت‌به‌کارت:** خریدار تصویر رسید را آپلود می‌کند. سفارش «در انتظار تأیید» می‌شود و ادمین در پنل تأیید یا رد می‌کند.
3. پس از پرداخت: برای دوره (یا همه دوره‌های پکیج) دسترسی ساخته می‌شود. اگر دسترسی فعال باشد، از تاریخ پایان قبلی تمدید می‌شود. فاکتور PDF هم قابل دانلود است.
4. کد تخفیف ۱۰۰٪ یعنی سفارش بدون پرداخت فعال می‌شود.

> API ربات بله سازگار با Telegram Bot API فرض شده است (`tapi.bale.ai`). اگر بله فیلدی را با نام دیگری بفرستد، پیاده‌سازی هر دو نام رایج را می‌پذیرد. در بدترین حالت، تأیید دستی در پنل همیشه کار می‌کند.

## کلاس زنده و پیامک‌ها

- **کلاس زنده** (`apps/live`): هر کلاس چند جلسه دارد و هر جلسه زمان، مدت و لینک Google Meet خودش را دارد. ثبت‌نام از همان مسیر خرید انجام می‌شود (بله، کارت‌به‌کارت یا کد تخفیف). لینک ورود فقط برای ثبت‌نام‌شده‌ها و از ۱۵ دقیقه قبل از شروع تا پایان جلسه نمایش داده می‌شود. ظرفیت هم قابل تنظیم است.
- **پیامک‌ها** (`apps/notify`) با قالب‌های sms.ir و در پس‌زمینه (Celery) ارسال می‌شوند و در صورت خطا تا ۳ بار دوباره تلاش می‌شود:
  - پرداخت تأیید شد: پارامترهای `#ORDER#` و `#TITLE#`
  - رسید رد شد: پارامتر `#ORDER#`
  - یادآوری کلاس، یک روز و یک ساعت قبل: پارامترهای `#TITLE#` و `#TIME#`
- **زمان‌بندی:** Celery beat داخل همان worker اجرا می‌شود (`-B`) و هر ۵ دقیقه جلسه‌های نزدیک را بررسی می‌کند. هر یادآوری فقط یک بار ارسال می‌شود.

## ویدیو

1. **آپلود:** ادمین از صفحه جلسه ویدیو را انتخاب می‌کند. مرورگر فایل را در قطعه‌های ۵ مگابایتی می‌فرستد و قطعه‌های ناموفق را خودکار دوباره ارسال می‌کند. به این ترتیب timeout پراکسی Coolify و قطعی اینترنت مشکلی ایجاد نمی‌کند.
2. **تبدیل:** Celery worker با ffmpeg ویدیو را به HLS با کیفیت‌های 1080p، 720p و 480p تبدیل می‌کند (بدون بزرگ‌نمایی ویدیوهای کم‌کیفیت‌تر). کدگذاری CRF با سقف بیت‌ریت است و هر قطعه ۶ ثانیه است. بعد از تبدیل موفق، فایل اصلی حذف می‌شود تا فضا آزاد شود.
3. **پخش:** پلیر hls.js کیفیت را بر اساس سرعت اینترنت انتخاب می‌کند و انتخاب دستی هم ممکن است. فایل‌های playlist و قطعه‌ها فقط بعد از بررسی دسترسی تحویل داده می‌شوند.
4. **واترمارک:** نام سایت و شماره موبایل دانشجو هر ۷ ثانیه جابه‌جا می‌شود و در حالت تمام‌صفحه هم دیده می‌شود.

## امنیت محتوا

- فایل‌ها و ویدیوها از مسیر عمومی سرو نمی‌شوند. Django دسترسی را چک می‌کند و فایل با لینک امضاشده و موقت تحویل داده می‌شود.
- روی پلیر، واترمارک متحرک «lms.araz.me + شماره موبایل کاربر» نمایش داده می‌شود.
